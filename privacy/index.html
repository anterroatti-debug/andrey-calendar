Политика конфиденциальности

Andrey Calendar Bot · редакция от 19 октября 2026 г.

Andrey Calendar Bot — личный Telegram-бот для работы с Google Календарём: создание событий, напоминания и ежедневная сводка. Бот предназначен для использования его владельцем.

Какие данные обрабатываются

  • Данные Google Календаря: события, их названия, даты, время и описания — только в объёме, разрешённом пользователем при авторизации.
  • Данные Telegram: идентификатор пользователя и сообщения, отправленные боту.
  • Технические данные: токены авторизации Google и временное состояние диалогов.

Зачем

Данные используются только для работы функций бота: показать события, создать или изменить событие по запросу пользователя, отправить напоминание или сводку. Данные не используются для рекламы, не продаются и не передаются третьим лицам.

Хранение

Токены авторизации и служебные данные хранятся на сервере бота с ограниченным доступом. Содержимое календаря в боте не накапливается: бот запрашивает его у Google в момент выполнения команды.

Google API

Использование и передача информации, полученной через API Google, соответствует Политике использования пользовательских данных сервисов Google API, включая требования об ограниченном использовании (Limited Use).

Privacy Policy

Andrey Calendar Bot · last updated October 19, 2026

Andrey Calendar Bot is a personal Telegram bot for Google Calendar: creating events, reminders and a daily summary. It is intended for use by its owner.

Data processed

  • Google Calendar data (events, titles, dates, times, descriptions), only within the scope the user grants.
  • Telegram user ID and messages sent to the bot.
  • Google authorization tokens and temporary dialog state.

Use

Data is used solely to provide the bot's features. It is not used for advertising, not sold and not shared with third parties.

Storage

Tokens and service data are stored on the bot's access-restricted server. Calendar content is fetched from Google on demand and is not accumulated by the bot.

Google API

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

You can revoke access at myaccount.google.com/permissions. To delete stored data, contact the address below.
